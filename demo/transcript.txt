# Save a different default provider
$ ws config set provider exa
saved to /tmp/ws-demo/config.toml
$ ws config show
provider     exa (config file)
gateway      default (default)
account id   set
api token    set
config file  /tmp/ws-demo/config.toml

# The environment overrides the saved default...
$ WS_PROVIDER=linkup ws config show
provider     linkup (environment)
gateway      default (default)
account id   set
api token    set
config file  /tmp/ws-demo/config.toml
$ WS_PROVIDER=linkup ws search precedence -n 1
1. precedence - result 1 from linkup
   https://example.com/linkup/1
   Linkup returns raw results from its 'fast' search depth.

1 result · provider linkup · gateway default · 0 ms · request mock-linkup-default

# ...and a flag overrides the environment
$ WS_PROVIDER=linkup ws search precedence -n 1 --provider ceramic

   https://example.com/ceramic/1
   Ceramic returns long excerpts from its own index of the web.

1 result · provider ceramic · gateway default · 0 ms · request mock-ceramic-default

# Mistakes are caught locally, before anything is billed (exit status 2)
$ ws search too many results --limit 11

[exit status 2]
$ ws search oops --provider google

[exit status 2]
